# Рабочее окружение pnFolder

Скрипты для правок библиотеки и API без релизов: собрать библиотеку локально, собрать все плагины против неё и сразу увидеть, что сломали.
Папка лежит в репозитории pnLibrary. Репозитории плагинов должны лежать **рядом** с ним, в одной общей папке:

```
pnFolder-repos/
  pnLibrary/        <- этот репозиторий, скрипты в pnLibrary/dev
  pnClans/ pnMarket/ pnCases/ ... (плагины)
```

| Система | Запуск | Установка команды `dev` |
|---|---|---|
| Windows | `.\dev.ps1` или `dev.cmd` (меню с цветами и прогрессом) | `.\install.ps1` один раз |
| Linux (Ubuntu) | `./dev.sh` (простое меню) | `./install.sh` один раз |

## Требования
- JDK 21 (на Windows ищется в `C:\Program Files\Eclipse Adoptium`, на Ubuntu: `sudo apt install openjdk-21-jdk`).
- `git`. На Ubuntu ещё `bash`, `find`, `grep` (есть по умолчанию).

## Команды (одинаковые на обеих системах)
| Команда | Что делает |
|---|---|
| `status` | ветки и несохранённые правки всех репозиториев |
| `lib-check` | тесты, spotless и проверка публичного API библиотеки |
| `lib-publish` | собрать библиотеку из рабочей папки в локальный Maven как `0.1.0-dev.local` |
| `plugins [имена\|all]` | собрать плагины против локальной библиотеки |
| `api-diff [тег]` | что изменилось в публичном API по сравнению с релизом (по умолчанию `v0.1.0-dev.6`) |
| `api-map` | обновить карту API (`dev/API-MAP.md`, в git не хранится) |
| `guard` / `unguard` | запретить / разрешить push в `main`, `master` и любые теги во всех репозиториях |

Примеры: `.\dev.ps1 plugins pnClans pnMarket` и `./dev.sh plugins pnClans pnMarket`.

## Цикл работы
1. Правишь библиотеку.
2. `lib-publish`: библиотека собирается как `0.1.0-dev.local`.
3. `plugins all`: все 13 плагинов собираются против неё. Плагины не меняются, версию подменяет `local.init.gradle`.
4. `api-diff`: что изменилось в API.
5. `lib-check` перед тем, как считать работу готовой.

Релизы не выпускаются, пока вы не скажете. Защиту от случайного push включает `guard`.

## Что не хранится в git
`test-build/` (собранные jar), `config.json` (путь к тестовому серверу и статистика меню), `API-MAP.md` (генерируется).
Меню с jar и тестовым сервером есть только на Windows (`menu.ps1`); на Linux меню проще, а сборка и проверки те же.
