# pnLibrary 1.1.0

## Новое

- Добавлено поле `changelogUrl` в release-каталог.
- В уведомлении об обновлении показывается краткое описание версии.
- Пользователь может открыть полный changelog на GitHub.
- Добавлены методы `delayTicks(...)` и `intervalTicks(...)` для задач.

## Совместимость

- Java 17 или новее.
- pnLibrary API 8.
- После установки требуется перезапуск сервера.
