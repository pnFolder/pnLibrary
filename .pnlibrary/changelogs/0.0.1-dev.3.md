# pnLibrary 0.0.1-dev.3

Development build.

## Changes

- Unified the `releases.json` artifact list: the `installer` block is gone, the embedded installer and plugin
  updates now read the same `artifacts` entries, with the new `"platform": "UNIVERSAL"` file covering all platforms.
- Catalog updates now actually verify the downloaded file's SHA-256 (it used to be dropped before reaching the check).
- `PluginLifecycle.hide(vararg LifecycleRow)` lets a plugin hide automatic rows from its enable/disable card.
- Console cards compute their own `┌ ├ └` connectors instead of relying on the caller to set them.
- Added the `examples/bootstrap-bukkit` demo plugin showing the installer and pnLibrary integration.
- Fixed a flaky `ReleaseCatalogGatewayTest` timeout on CI.
