# Консольные сообщения pnLibrary на ConsoleCard

Настоящий текст, снятый при запуске кода (тестовые данные), цветовые коды убраны, ничего не сокращено. Все различающиеся варианты каждой карточки.

У каждой карточки одно и то же: наверху `плагин@модуль версия` (если сообщение про весь плагин, модуль называется `main`), внизу блок «Поддержка» со ссылкой на Discord.
