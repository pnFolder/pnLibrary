# Удалённые политики

Политика — один `.java`-файл по ссылке `https://` или `file:`, не больше 1 МБ. Сервер компилирует его
собственным JDK (нужен JDK, а не JRE), поэтому дополнительные файлы не требуются. Ошибка
политики обрабатывается согласно `onError`.

Исполняемые политики — доверенный код с полномочиями JVM сервера. ClassLoader не является
песочницей. Для фиксированной версии исходника передайте `RemotePolicySettings.builder().sha256(...)`:
runtime проверит точные загруженные байты до компиляции. Хеш следует получать из доверенного
канала. Предпочтителен URL, закреплённый на commit, а не изменяемую ветку.

Встроенная бизнес-политика pnLibrary сохраняет своё прежнее поведение и Java-реализацию.
Неизвестный или недоверенный исполняемый код требует отдельного процесса с ограничением времени
и полномочий; этот механизм не предназначен для его безопасного запуска внутри сервера.
