# Удалённые политики

Политика — один `.java`-файл по ссылке `https://` или `file:`, не больше 1 МБ. Сервер компилирует его
своим javac. Если сервер запущен на JRE без компилятора, тот же загрузчик Libby, что берёт Kotlin, при первой проверке политики
докачивает компилятор ECJ (около 3 МБ, SHA-256 зашит в коде) в `libraries/pnlibrary`, и политика компилируется им,
поэтому JDK не нужен. Если докачать не удалось, проверка политики сообщает об этом, дальше действует `onError`. Политика всегда собирается под Java 8 и работает на любой Java. Ошибка
политики обрабатывается согласно `onError`.

Исполняемые политики — доверенный код с полномочиями JVM сервера. ClassLoader не является
песочницей. Защита политики — доступ к репозиторию, где она лежит: храните её в репозитории с ограниченной записью.

Встроенная бизнес-политика pnLibrary сохраняет своё прежнее поведение и Java-реализацию.
Неизвестный или недоверенный исполняемый код требует отдельного процесса с ограничением времени
и полномочий; этот механизм не предназначен для его безопасного запуска внутри сервера.
