# Обзор pnLibrary: что умеет библиотека

Документ для человека и для нейросети. Сначала короткая карта, потом ссылки на подробные страницы.
Нейросети: правила подключения плагина лежат в [integration/AGENTS.md](../integration/AGENTS.md).

## Что это

pnLibrary — один jar на сервер (Bukkit/Paper/Folia, BungeeCord, Velocity), который даёт всем плагинам pnFolder общие
сервисы. Плагин подключает только API (`compileOnly`), реализация живёт на сервере.

## Как плагин начинает работать

```kotlin
val library = PnLibraryProvider.get()          // в plugin.yml: depend: [pnLibrary]
val context = library.plugins.register(this)   // ModuleContext плагина
```

Через `ModuleContext` плагин получает все сервисы ниже; всё, что он зарегистрировал, закрывается вместе с ним.

## Как работают обновления

1. **Установка.** Bootstrap-плагин (`modules/bootstrap`) скачивает pnLibrary с GitHub и кладёт её в `plugins/`.
2. **Проверка.** Сразу при старте и затем каждые `checks.interval` (по умолчанию 6 часов, минимум 5 минут)
   библиотека читает каталоги `releases.json` самой себя и зарегистрированных плагинов. Выключить проверки нельзя.
3. **Канал.** Берётся самый новый релиз, который разрешает канал: `stable` < `rc` < `beta` < `alpha` < `dev`.
   Канал pnLibrary задаётся в `updates.yml` (`library.channel`), канал плагина — командой
   `/pn updates set <плагин> channel <канал>` или в `PluginUpdateRequest`.
4. **Подготовка.** Файл скачивается, сверяется SHA-256, кладётся в транзакцию. Jar не заменяется на ходу.
5. **Применение.** Только при следующем запуске сервера; сервер сам не перезапускается.
6. **Откат и журнал.** Резервные копии и история действий хранятся; `/pn updates history`.

Пока у pnLibrary нет ни одного `stable`-релиза (сейчас все релизы — `dev`), по умолчанию стоит канал `dev`, иначе
библиотека после установки не нашла бы обновлений. Когда появится стабильная ветка, значение по умолчанию станет
`stable`. Уже созданный `updates.yml` не перезаписывается: канал в нём меняется вручную.

## Поддержка

В консоли при запуске и выключении плагинов pnFolder показывается блок с приглашением в Discord на русском и английском;
тот же текст лежит в шапке `config.yml`. Отключить его нельзя.
