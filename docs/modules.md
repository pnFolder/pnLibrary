# Модули плагина: включить, выключить, перезапустить

Плагин делится на модули (`registration.registerModule(...)`). Если модуль зарегистрирован вместе с `PluginModule`,
администратор может переключать его командами и в меню, не перезапуская сервер.

```kotlin
class Shop : PluginModule {
    override fun onEnable(context: ModuleContext) {
        context.registerCommand("shop") { /* ... */ }
    }
    override fun onDisable(context: ModuleContext) { /* закрыть то, что открыл сам */ }
    override fun onReload(context: ModuleContext): Boolean {
        // перечитать настройки на месте; false значит «не умею», тогда модуль перезапустится
        return false
    }
}

registration.registerModule("shop", Shop())
```

Методы пустые по умолчанию, переопределяйте нужные. При выключении библиотека сама отменяет задачи модуля и снимает его
команды. Слушатели и всё, что модуль открыл сам, закрывается в `onDisable`.

`context.control` (`ModuleControl`) даёт то же из кода: `state` (`ENABLED`, `DISABLED`, `FAILED`), `lastError`, `enable()`,
`disable()`, `restart()`, `reload()`, `autoStart`/`setAutoStart(...)`. Ошибка в методе не выбрасывается: модуль становится
`FAILED`, ошибка видна в `lastError`, команде и меню, а `enable()` пробует ещё раз. Модуль без `PluginModule` виден в списке,
но не переключается.

## Команды

| Команда | Что делает |
|---|---|
| `/pn modules` | все модули и их состояние |
| `/pn modules view <плагин:модуль>` | карточка: состояние, ошибка, автозапуск, кнопки |
| `/pn modules enable\|disable\|restart\|reload <плагин:модуль>` | переключить сейчас |
| `/pn modules auto <плагин:модуль> on\|off` | включать ли модуль вместе с сервером (сохраняется) |

Право: `pnlibrary.modules`; консоль может всегда. Вместо `плагин:модуль` можно написать просто id модуля, если он один.

## Меню

Главное меню, «Модули плагинов»: список и карточка с кнопками «Включить», «Выключить», «Перезапустить», «Перечитать»,
«Включать с сервером». В карточке плагина обновлений есть кнопка «Модули» только с его модулями. Всё, что есть в меню, есть и
командой, и наоборот.

## Что запоминается

Модули, которые администратор оставил выключенными, хранятся в `data/modules/preferences.json` (`{"disabled": [...]}`).
Такой модуль не запускается при старте сервера, пока его не включат командой или кнопкой «Включать с сервером».
