# Кулдауны

`module.cooldowns` хранит паузы на пару «кто» (`UUID`) и «что» (имя действия). Время идёт по монотонным часам, не зависит
от смены системных часов и живёт, пока работает модуль. Имя действия сравнивается без регистра и пробелов по краям.

```kotlin
val result = module.cooldowns.acquire(player.uniqueId, "kit", Duration.ofMinutes(10))
if (!result.allowed) {
    player.sendMessage("Подождите ещё ${result.remaining.seconds} с")
    return
}
giveKit(player)
```

| Метод | Что делает |
|---|---|
| `acquire(кто, что, срок)` | атомарно включает паузу, если её нет; иначе отказ с остатком |
| `has`, `remaining` | есть ли пауза и сколько осталось |
| `set` | ставит срок (ноль снимает) |
| `extend` | продлевает от текущего срока или от сейчас |
| `reset` | снимает одну паузу |
| `active(кто)` | все действующие паузы игрока с остатком, самые долгие первыми |
| `clear(кто)` | снимает все паузы игрока, например при выходе; возвращает сколько снято |
| `clear()` | снимает все паузы модуля |
| `size` | сколько пауз действует сейчас |

Просроченные записи удаляются по ходу работы (каждые 256 записей и при чтении), поэтому игрок, к которому больше не
обращаются, не копится в памяти. Закрытый сервис отвергает чтение и создание, а очистка остаётся безопасной.

Паузы не сохраняются между запусками сервера. Нужна пауза, переживающая перезапуск, храните срок в своих данных.
