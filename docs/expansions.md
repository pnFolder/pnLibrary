# Расширения

Расширение (`Expansion`) — общая возможность, которую pnLibrary запускает, останавливает и в конце закрывает как одно целое, как
расширение PlaceholderAPI. Плагины pnFolder используют их, чтобы делиться службами, не зная друг о друге.

## Жизненный цикл

`ExpansionState`: `DISABLED` → `ENABLED` → `DISABLED` … → `CLOSED`. Если запуск упал, расширение получает `FAILED`, ошибка
пишется в журнал, остальные расширения не страдают; запустить `FAILED` можно снова вызовом `enable()`. `CLOSED` необратим.

## Написать расширение

Наследуйте `AbstractExpansion`: он сам ведёт состояние, вам нужно только занять и освободить ресурсы.

```kotlin
class WeatherExpansion : AbstractExpansion("weather") {
    override fun onEnable() { /* занять ресурсы */ }
    override fun onDisable() { /* освободить их */ }
}
```

`id` уникален во всей библиотеке: второе расширение с тем же `id` бросает `IllegalStateException`.

## Зарегистрировать

Через контекст модуля. Всё, что зарегистрировал модуль, отключается и снимается, когда он закрывается, вручную ничего хранить не надо:

```kotlin
module.expansions.register(WeatherExpansion())
```

Найти чужое расширение:

```kotlin
val weather = module.expansions.get(WeatherExpansion::class.java)   // или get("weather"); null, если не зарегистрировано
```

Глобальный реестр `PnLibrary.expansions` читает те же данные. Ручная `register` там возвращает `AutoCloseable`: закрытие снимает расширение.

## Что нельзя

Собственные службы библиотеки (например, общая локализация) лежат в отдельном внутреннем реестре. Плагин не может отключить их через
публичный `expansions.get(...)`.
